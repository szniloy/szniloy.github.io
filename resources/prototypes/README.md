# Prototypes

Files used by project prototypes.

- `food-app/` holds the photos shown inside the built-in Food App prototype.
- To add your own web prototype (for example an exported HTML prototype), put it in its own folder,
  e.g. `resources/prototypes/myapp/index.html`, and use it in `js/project-demos-config.js`:
  `type:'embed', src:'resources/prototypes/myapp/index.html'`
